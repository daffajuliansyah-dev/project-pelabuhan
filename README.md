# PORTARA — Smart Port Command Center

Versi demo presentasi Sistem Informasi Pelabuhan Digital. Aplikasi ini dapat dijalankan langsung di browser tanpa instalasi database, Composer, atau NPM.

## Cara menjalankan

1. Unduh branch **presentasi-upgrade** sebagai ZIP.
2. Ekstrak ZIP.
3. Klik dua kali file **index.html**.
4. Pilih role pada halaman awal. Tidak ada password untuk mode presentasi.

## Tiga role

- **Administrator** — dashboard lengkap, analitik, transaksi, dan manajemen user.
- **Customer** — booking, tracking kapal, e-ticket, pembayaran, dan layanan.
- **Petugas Pelabuhan** — pemantauan operasional, konfirmasi jadwal, validasi QR, dan laporan insiden.

## Lima fitur utama

1. Smart Jadwal & Booking Dermaga
2. Live Vessel Tracking
3. E-Ticket & QR Validation
4. Tagihan Digital
5. Pusat Layanan & Insiden

## Alur demo cepat

1. Masuk sebagai **Administrator** dan tunjukkan dashboard serta Manajemen User.
2. Keluar, masuk sebagai **Customer**, lalu buat booking baru dan buka E-Ticket.
3. Buka Tagihan Digital dan tekan tombol **Bayar**.
4. Keluar, masuk sebagai **Petugas Pelabuhan**, lalu buka E-Ticket dan lakukan simulasi scan.
5. Buka Tracking Kapal, aktifkan mode 3D, kemudian buat laporan insiden.

Data demo baru disimpan secara lokal pada browser sehingga tetap tersedia setelah halaman dimuat ulang.
